# XBoard 微信 Native 支付插件

适用于 XBoard 的微信支付 Native APIv3 插件，当前版本面向普通商户。插件包含 Native 下单、APIv3 请求签名、微信支付应答和回调验签、AES-256-GCM 回调解密，以及 APPID、商户号、订单金额和币种校验。

## 安装

将本目录打包成 ZIP 文件，在 XBoard 插件管理页面上传、安装并启用。插件代码为 `wechatpay`，安装后的目录应为 `plugins/Wechatpay`。

## 配置

- 与商户号绑定的 APPID
- 普通商户号 `mchid`
- 商户 API 证书序列号
- `apiclient_key.pem` 中的商户 API 证书私钥
- 32 字节 APIv3 密钥
- 以 `PUB_KEY_ID_` 开头的微信支付公钥 ID
- 微信支付公钥
- 可选商品描述

XBoard 后台显示的异步通知地址必须能通过公网 HTTPS 访问，且代理或 CDN 必须保留 `Wechatpay-*` 请求头。插件返回官方 `code_url`，XBoard 会使用现有二维码组件展示。

## 安全说明

商户私钥和 APIv3 密钥只能保存在服务端支付配置中，禁止写入日志、客户端或公共代码仓库。只有在回调验签、解密、商户身份校验和订单金额校验全部通过后，订单才会被标记为已支付。

> 本 PHP 实现依据微信支付官方 APIv3 文档实现，属于参考实现，非微信支付官方维护。正式上线前请审查代码，并使用真实商户配置完成全链路测试。
